API Documentation

How to use the ShowWise Backend API

Available Endpoints

GET /api/health

Health check endpoint. Returns service status and version.

GET /api/organizations

Returns all organizations with their complete configuration.

GET /api/organizations/{slug}

Returns a specific organization by its slug identifier.

GET /api/organizations/by-subdomain/{subdomain}

Finds an organization by its subdomain. Useful for subdomain-based routing.

GET /api/stats

Returns statistics about organizations and API usage.

Example Usage 

// Fetch all organizations
fetch('http://your-backend-url/api/organizations')
  .then(res => res.json())
  .then(data => console.log(data));

// Get specific organization
fetch('http://your-backend-url/api/organizations/demo')
  .then(res => res.json())
  .then(data => console.log(data));
