Kill Switch Management

Emergency instance shutdown & licence key controls

⚠️ Critical Feature

Kill switches remotely disable instances. Each instance holds a licence key issued from this dashboard. The instance pings POST /api/kill-switch/ping at its configured interval. When the remaining TTL is ≤ 2× the ping interval, a new key is issued automatically. If the backend is unreachable the instance trusts its cached key until it expires.

How the Licence-Key System Works

  1. Issue a key with the desired validity period using the form above.
  2. The instance stores the key to disk (.license_key) and presents it on every ping.
  3. When remaining TTL ≤ 2 × the instance's PING_INTERVAL, the backend issues a fresh key in the same response — no manual action needed.
  4. If the backend is unreachable, the instance continues running until its cached key expires (fail-open while valid, fail-closed on expiry).
  5. Enabling the kill switch suspends the instance regardless of key validity.
Relevant env vars on instances:
PING_INTERVAL=300 CONFIG_REFRESH=3600 LICENSE_KEY_FILE=.license_key
